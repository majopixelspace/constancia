# Constancia — Paquete de exploración de concepto

Sitio estático de Pixelspace. Punto de entrada: `index.html`.

## Piezas
- `index.html` — índice del paquete
- `constancia.html` — el concepto (deck, 25 slides)
- `momentos-historia-01.html` — cinco historias / wireframes (38 slides)
- `pantallas.html` — las pantallas (dirección visual)
- `constancia-narrativa.pdf` / `.docx` — la narrativa (10 páginas)

## Deploy
Sitio 100 % estático, sin paso de build.
En Render: **Static Site** → Publish directory `.` → Build command vacío.
La configuración también está declarada en `render.yaml`.

> Textos, montos y nombres de las historias son ficticios. Documento confidencial.
